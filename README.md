I build the software small teams use every day, and keep it running long after launch. Most of it is internal tools, integrations and automation: connecting the systems a business already relies on so people stop copying data by hand.

Based in Taguig, Philippines (UTC+8). Open to part-time and contract work.

### 🛠️ Things I've Built

| Project | What it is | |
|---|---|---|
| **Bathala** | A Filipino-folklore card roguelike that adjusts its difficulty to how you play. GDAP GameOn 2025 finalist, CCIS 2026 Best Game Development. | [Play](https://playbathala.exadizon.work) |
| **ALARP** | X-ray collimation practice for radiologic technology students, scored on every shot. Tested by 100+ students. | [Live](https://alarp.exadizon.work) |
| **Palad** | Free Filipino Sign Language lessons in the browser, with clips of Deaf signers and an on-device camera mirror. | [Live](https://palad.exadizon.work) |
| **HandInCare** | Sign recognition that runs on the phone, so nurses can talk with Deaf patients offline. Top 2, Project RISE. | [Site](https://www.handincare.org) |
